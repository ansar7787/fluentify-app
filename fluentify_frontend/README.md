# SpeakPay – Fintech-Enabled English Speaking App

SpeakPay is a speaking-first English learning app built with Flutter that combines AI-driven speaking practice with affordable fintech-powered payments for Indian students and early professionals.

## 🚀 Core Idea
A **“Speak & Earn”** English speaking app where users practice speaking daily with AI and peers, and pay tiny subscriptions or pay-per-session using UPI/PayLater.

## ✨ Key Features
- **Speaking-first design**: Focus on talking, not just tapping.
- **Micro-missions**: 3–10 minute roleplays, interview prep, and daily life conversations.
- **Fintech Layer**: Very low-ticket pricing (₹19/₹29/₹49) with UPI and PayLater support.
- **Indian Focused**: Content targeted to Indian interviews, tech jobs, and university presentations.
- **AI Feedback**: Get instant feedback on fluency, pronunciation, and vocabulary.

## 🛠️ Tech Stack
- **Frontend**: Flutter (Clean Architecture)
- **Backend**: NestJS (TypeScript, TypeORM, PostgreSQL)
- **AI**: Speech-to-Text & Feedback API
- **Payments**: Razorpay (UPI, PayLater)

## 🏗️ Getting Started
### Prerequisites
- Flutter SDK
- Node.js & npm
- PostgreSQL

### Backend Setup
1. CD into `speakpay_backend`
2. `npm install`
3. Configure `.env`
4. `npm run dev`

### Frontend Setup
1. `flutter pub get`
2. Configure `.env`
3. `flutter run`
