# SpeakPay Backend API

NestJS powered backend for SpeakPay application.

## 🏗️ Architecture
- **NestJS**: Modular architecture
- **TypeORM**: Database ORM
- **PostgreSQL**: Primary database
- **JWT**: Secure authentication
- **Razorpay**: Payment gateway integration

## 🚀 Features
- **User Management**: Profile tracking and CEFR levels.
- **Mission Engine**: AI-driven speaking missions and scoring.
- **Fintech Integration**: Subscription management and UPI payments.
- **Analytics**: User progress and speaking metrics.

## 🛠️ Setup
1. `npm install`
2. Create `.env` file based on `.env.example`
3. `npm run dev`

## 🧪 Testing
- `npm run test`
- `npm run test:e2e`
