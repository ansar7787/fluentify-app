# Fluentify

Fluentify is a comprehensive application designed to help users improve their language fluency through interactive tools and features.

## Project Structure

This project consists of two main components:

- **fluentify_frontend**: A Flutter-based mobile application acting as the client side.
- **fluentify_backend**: The server-side logic and database interactions.

## Features

- **Interactive Learning**: Engaging lessons and exercises.
- **Progress Tracking**: Monitor your improvement over time.
- **Video Integration**: Watch and learn from video content.
- **User Profiles**: Personalized experience with avatars and stats.
- **Leaderboards**: Compete with others to stay motivated.
